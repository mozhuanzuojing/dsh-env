## 1. 适用场景与目标业务行为

采购到货后办理入库，以及已入库物料的退货入库。目标行为：**按实收数量形成可追溯的库存台账，并使采购单据的到货进度与库存同步**。
不覆盖：采购下单与供应商对账（`采购管理`）、质检判定（`质量管理`，质检未通过的到货不得入库）。

## 2. 单据与字段口径

| 字段 | 含义 | 来源 | 校验 |
|---|---|---|---|
| 入库单号 | 单据唯一标识 | 系统按规则生成 | 不可重复 |
| 入库类型 | 采购入库 / 退货入库 / 其它入库 | 人工选择 | 必填 |
| 来源单据 | 采购订单/到货单号 | 关联带出 | 采购入库必填（`R-KC-002`） |
| 仓库 | 收货仓库 | 人工选择 | 必填，须在用户数据范围内 |
| 物料 | 入库物料 | 来源单据带出，可增行 | 必填，须为启用状态 |
| 数量 | 实收数量 | 人工录入 | > 0，按单位精度（`R-KC-006`） |
| 批次 | 批次号 | 人工录入或规则生成 | 启用批次管理的物料必填 |
| 计量单位 | 单位 | 物料带出 | 与物料主数据一致 |

## 3. 状态机

| 状态 | 说明 | 允许流转到 | 触发动作 | 所需权限 |
|---|---|---|---|---|
| 草稿 | 未提交 | 待审核、已作废 | 保存、提交、作废 | 制单 |
| 待审核 | 已提交待审 | 已审核、草稿（驳回） | 审核、驳回 | 审核 |
| 已审核 | 已动账 | —（不可逆） | —（如需冲销另开红字单） | — |
| 已作废 | 终止 | — | 作废 | 制单 |

## 4. 业务规则

| 编号 | 规则 |
|---|---|
| `R-KC-001` | 入库数量必须大于 0 |
| `R-KC-002` | 采购入库必须关联采购订单或到货单，且数量不得超过未到货数量 |
| `R-KC-003` | 质检状态为"不合格"的到货不允许入库 |
| `R-KC-004` | 启用批次管理的物料，批次号必填且同仓库同物料同批次可合并 |
| `R-KC-005` | 单据审核后才写库存台账，草稿与待审核不动账 |
| `R-KC-006` | 数量按物料计量单位精度取整，中间过程不取整 |
| `R-KC-007` | 已审核单据不可修改、不可删除，只能以红字单据冲销 |
| `R-KC-008` | 仓库必须在制单人的数据范围内，否则整单不可保存 |

## 5. 校验与异常

| 触发条件 | 提示 | 错误码 |
|---|---|---|
| 数量 ≤ 0 | 入库数量必须大于 0 | `KC_QTY_INVALID` |
| 缺来源单据 | 采购入库必须关联来源单据 | `KC_SOURCE_REQUIRED` |
| 超未到货数量 | 入库数量超过可入库数量 | `KC_QTY_EXCEED` |
| 质检不合格 | 该到货质检不合格，不允许入库 | `KC_QC_REJECTED` |
| 缺批次 | 该物料启用批次管理，请填写批次号 | `KC_BATCH_REQUIRED` |
| 越权仓库 | 仓库不在您的数据权限范围内 | `KC_WAREHOUSE_DENIED` |

## 6. 权限与可见性

| 角色 | 可见 | 可改 |
|---|---|---|
| 制单人 | 本人 + 本部门单据 | 草稿（可编辑、可删除） |
| 审核人 | 数据范围内的待审核单 | 仅审核/驳回 |
| 库管 | 本仓库全部单据 | 已审核单只读 |

## 7. 联动与接口

| 方向 | 对象 | 触发 | 说明 |
|---|---|---|---|
| ← | `采购管理` | 到货单 | 带出物料、数量、供应商 |
| → | `库存台账` | 审核通过 | 增加库存，记流水 |
| → | `采购管理` | 审核通过 | 回写来源单据的到货进度 |
| → | `财务管理` | 审核通过 | 生成暂估入库凭证（按项目是否启用） |

## 8. 验收场景

| # | Given | When | Then |
|---|---|---|---|
| 1 | 采购到货 100、质检合格 | 制单并审核 | 库存台账 +100，来源单据到货进度更新（`R-KC-002`/`R-KC-005`） |
| 2 | 到货 100、已入库 60 | 再入 50 | 拒绝，提示超可入库数量（`KC_QTY_EXCEED`） |
| 3 | 单据为草稿 | 直接改库存 | 台账不变（`R-KC-005`） |
| 4 | 已审核单据 | 尝试编辑 | 拒绝，只能红字冲销（`R-KC-007`） |
| 5 | 物料启用批次管理 | 不填批次保存 | 拒绝并提示（`KC_BATCH_REQUIRED`） |
